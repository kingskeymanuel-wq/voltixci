Dictionnaire

Codes d'erreur et leur signification

Tapez le code ou le message tel qu'il s'affiche (ex. 0x80040220, SIP 503, 32767, DNS_PROBE…). Chaque code est expliqué simplement, avec les causes, quoi faire et la fiche à suivre.

Lire un code : les codes en 0x… viennent de Windows et des logiciels Microsoft (Office, Microsoft Engage). Les codes à 3 chiffres sont des codes web (HTTP) ou téléphoniques (SIP). Les codes Cisco à 5 chiffres (32767, 50010…) expliquent pourquoi un agent a changé d'état.
